# System Overview

## Core Purpose
A web application developed for the **Legal Affairs Division (LAD), Office of the Permanent Secretary, Ministry of Public Health (MOPH)**, Thailand. It serves as a centralized repository for:
- **Memorandum of Understanding (MOU)** documents.
- **Public Health Laws** and related legal documents.

## Technical Stack
- **Framework:** CodeIgniter 4.5+ (AppStarter)
- **PHP Version:** ^8.1
- **Database:** MySQL 8.0+ (utilizing UUIDs and Full-text indexes)
- **Authentication:** [CodeIgniter Shield](https://github.com/codeigniter4/shield) (Session-based)
- **Frontend:**
  - **CSS:** Tailwind CSS v4 (via PostCSS)
  - **Icons:** Font Awesome 6.7.2 (latest)
  - **Fonts:** Custom Thai fonts (ChulabhornLikit, Sarabun)
  - **JS:** Vanilla JS + Toastify.js
- **Testing:** PHPUnit 10+
